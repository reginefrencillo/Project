A robust starting template for Django and Django REST Framework (DRF) projects with production-ready configurations.

## ✨ Features

- **Pre-configured Django & DRF Setup** - Ready-to-use project structure with best practices
- **Environment Management** - `.env` support via `python-dotenv` for secure configuration
- **Database Flexibility** - Supports PostgreSQL, MySQL, and SQLite out of the box
- **Media Handling** - Pre-configured media and static files setup
- **Development Tools** - Includes commonly used packages for rapid development
- **Production Ready** - Basic configurations for deployment (ASGI/WSGI, CORS, etc.)
- **Git Optimized** - Comprehensive `.gitignore` to keep your repo clean

## 📦 Included Packages

- Core:
  - Django
  - Django REST Framework
  - python-dotenv

- Development:
  - django-debug-toolbar (for local development)
  - drf-spectacular (API documentation)

- Database:
  - psycopg2-binary (PostgreSQL support)
  - mysqlclient (MySQL support)
